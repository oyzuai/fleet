# Contributing to fleet

Thanks for your interest in contributing.

## Contributor License Agreement

All contributions require a signed [Contributor License Agreement](CLA.md)
(CLA) before they can be merged. You keep the copyright in your work. The CLA
grants the licensor, currently Micah Martin, a license to use, distribute and
relicense your contribution under any terms, including the project's license
and the Apache License 2.0 conversion that FSL-1.1-ALv2 provides. It also lets
the licensor assign those rights to a successor, such as a company formed to
steward fleet, so the whole project can move together.

You will be asked to sign the CLA when you open your first pull request. Pull
requests from contributors without a signed CLA will not be merged.

## Pull requests

- Keep each pull request focused on one change.
- Describe what changes for users and why.
- Make sure builds and tests pass.

## Security issues

Do not open public issues for security vulnerabilities. Contact the
maintainers privately instead.
